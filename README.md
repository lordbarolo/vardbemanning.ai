# vårdbemanning ai

Jag ska bygga appen Vårdbemanning.ai från grunden. Apppen ska erbjuda smarta verktyg och AI som underlättar de administrativa och affärsmässiga delarna för vårdens konsulter. 

Jag vill att projektet ska vara fristående och ej ha minnen eller kopplingar till andra projekt i mitt workspace initialt. 

Jag kommer att börja med att hämta design tokens från ett annat projekt samt enstaka tabeller.

appen ska vara lika funktionell för agenter som för människor. Användare ska kunna skapa en profil bakom inlogg där de ska ha tillgång till en AI-assistent samt möjlighet att ladda upp dokument. 

Appen ska koppla mot andra system med hjälp av API, dock inte initialt.

Appen har som ambition att vara bäst på agentic search för data kopplad till svensk vårdbemanning.
